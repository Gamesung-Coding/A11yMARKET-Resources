## 페르소나1: 정민우

1. 시작/환경

- **접근성 프로필**
  - As a 스크린리더 사용자 정민우는,
  - I want 로그인 시 이전에 설정한 '접근성 프로필'이 적용되어, 스크린 리더에 최적화된 화면을 마주하고 싶다.
  - so that 매번 설정을 다시 찾지 않고도 일관된 환경에서 쇼핑을 시작할 수 있다.
- **페이지 전환 안내**
  - As a 화면이 전환 되었음을 인지할 수 없는 정민우는,
  - I want 페이지가 바뀌는 순간 현재 위치와 다음 행동을 TTS로 안내 받고 싶다.
  - so that 화면 피드백이 없어도 내가 어디에 있는지 불안하지 않고 쇼핑을 이어갈 수 있다.
- **빠른 이동 안내**
  - As a 복잡한 화면이 부담스러운 정민우는,
  - I want 시작하자마자 홈, 장바구니, 마이페이지로 바로 가는 방법을 안내받고 싶다.
  - so that 헤매지 않고 필요한 곳으로 금방 갈 수 있다.
- **키보드만으로 전체 탐색**
  - As a 마우스를 사용할 수 없는 정민우는,
  - I want 모든 기능을 Tab, 방향키, Enter 만으로 조작하고 싶다.
  - so that 스크린 리더와 함께 완전한 온라인 쇼핑 경험을 누릴 수 있다

---

2. 탐색/검색/필터

- **검색 결과 수 안내**
  - As a 검색 결과를 시각적으로 볼 수 없는 정민우는,
  - I want “총 32개의 결과가 있습니다” 같은 안내를 듣고 싶다.
  - so that 검색 결과의 개수와, 검색이 성공했는지 실패했는지 바로 알 수 있다.
- **정렬/필터 변화 안내**
  - As a 필터링 후 변화가 궁금한 정민우는,
  - I want 필터를 적용하면 “가격이 낮은 순으로 정렬되었습니다”라고 음성 안내를 듣고 싶다.
  - so that 상품 탐색 중 변화를 놓치지 않고 정확한 탐색이 가능하다.
- **명확한 버튼 라벨**
  - As a 스크린리더로 버튼을 탐색하는 정민우는,
  - I want 모든 버튼이 ‘장바구니 담기’, ‘결제하기’ 처럼 실제 행동을 설명해주길 바란다.
  - so that 불필요한 선택 실수 없이 안정적으로 페이지를 탐색할 수 있다.
- **간단 요약 먼저 듣기**
  - As a 긴 설명을 한 번에 기억하기 어려운 정민우는,
  - I want 상품을 열면 핵심 내용부터 짧게 먼저 들었으면 한다.
  - so that 중요한 정보를 놓치지 않고 빨리 판단할 수 있다.
- **이미지 설명 듣기**
  - As a 사진을 볼 수 없는 정민우는,
  - I want 상품 사진이 무엇을 보여주는지 말로 들을 수 있길 바란다.
  - so that 어떤 물건인지 머릿속에 그릴 수 있다.

3. 장바구니

- **담기 성공/실패 안내**
  - As a 화면 변화를 알아채기 힘든 정민우는,
  - I want 장바구니에 담았을 때 성공했는지 아닌지를 바로 알려줬으면 한다.
  - so that 담기가 성공했는지 실패했는지 확신하고 다음 단계로 갈 수 있다.
- **장바구니 요약 안내**
  - As a 한눈에 보기가 어려운 정민우는,
  - I want 장바구니에 뭐가 몇 개 있고 얼마인지 짧게 바로 들을 수 있길 바란다.
  - so that 현재 장바구니 상태를 금방 파악하고 결정할 수 있다.

4. 결제

- **로그인 중단 없이 이어가기**
  - As a 비로그인 상태에서 결제를 눌렀을 수도 있는 정민우는,
  - I want 로그인을 하더라도 방금 하던 결제 화면으로 자연스럽게 돌아가길 바란다.
  - so that 흐름이 끊기지 않고 결제를 진행할 수 있다.
- **인증/오류 이유를 정확히 듣기**
  - As a 실패 원인을 알아야 하는 정민우는,
  - I want 인증이 틀리거나 연결이 끊기면 이유와 해결 방법을 바로 듣고 싶다.
  - so that 혼자서도 다시 시도해 해결할 수 있다.
- **결제 단계 안내**
  - As a 결제가 가장 불안한 정민우는,
  - I want 결제가 몇 단계 중 몇 단계인지, 지금 무엇을 하면 되는지 자세히 안내받고 싶다.
  - so that 당황하지 않고 결제를 끝까지 따라갈 수 있다.
- **최종 검토 요약 듣기**
  - As a 최종 결제 전 마지막 확인이 필요한 정민우는,
  - I want 결제 직전에 상품, 수량, 금액, 배송지를 짧게 요약해 주었으면 한다.
  - so that 틀린 부분 없이 안심하고 결제할 수 있다.

5. 주문/사후

- **주문 조회**
  - As a 주문상태가 궁금한 정민우는
  - I want 마이페이지의 주문 내역에서 내가 주문한 상품의 상태와 도착 예정일을 스크린리더로 명확히 확인하고 싶다.
  - so that 주문한 상품이 현재 어떤 상태인지 알 수 있다.
- 주문 취소 요청
  - As a 이미 결제했지만 마음이 바뀔 수 있는 정민우는,
  - I want 주문내역에서 해당 주문의 취소 사유를 고르고 ‘취소하기’를 누르면 취소가 접수되었음과 이후 진행 안내를 바로 듣고 싶다.
  - so that 헤매지 않고 지금 무엇이 어떻게 처리되는지 분명히 알 수 있다.
- 구매 확정
  - As a 상품을 받아보고 만족했다면,
  - I want 주문내역에서 구매를 간단히 확정할 수 있길 바란다.
  - so that 구매를 깔끔히 마무리할 수 있다.

## 페르소나2: 김복순

- **접근성 프로필**
  - As a 글씨가 잘 보이지 않는 김복순은
  - I want 글씨가 크고 화면은 선명하게 설정 하여 편안하게 보고 싶다,
  - so that 눈의 피로없이 편안하게 쇼핑을 즐길 수 있다.
- **(AI 요약)**
  - As a 노안으로 화면을 읽기가 어려운 김복순은
  - I want 상품설명을 100자 이내 쉬운 말로 삼품의 상세 내용과 주의 사항까지 제공하는 AI요약을 받고싶다.
  - so that 모르는 용어에 혼란 없이 남편에게 맞는 상품인지 즉시 판단 할 수있다.
- **(TTS)**
  - As a 글자를 오래 읽기 어려운 김복순은
  - I want 상품의 요약 정보를 버튼 하나로 손쉽게 들을 수 있는 TTS 기능을 원한다
  - so that 눈의 피로 없이 핵심 정보를 손쉽게 알 수 있다
- **플랫폼 신뢰시스템**
  - As a 온라인 사기가 걱정되는 김복순은
  - I want 상품 목록에서 ‘인증 판매자’ 마크가 붙은 상품을 쉽게 구별하고 싶다.
  - so that 믿을 수 있는 판매자의 상품을 안심하고 구매할 수 있다.
- **상품 결제(간편결제)**
  - As a 결제 과정이 어려운 김복순은
  - I want 카카오페이 등 익숙한 간편결제 버튼 하나로 결제 하고싶다
  - so that 본인인증과 카드번호 입력 없이 안심하고 빠르게 주문을 완료할 수 있다.
- **(UI 단순화)**
  - As a 수많은 정보와 광고에서 어려움을 느끼는 김복순은
  - I want 한 화면에 단순하고 하나의 기능만 명확히 보여주길 원한다
  - so that UI의 단순한 구조로 쇼핑을 쉽고 간편하게 즐길 수 있다.
- **주문 취소**
  - As a 실수로 잘못 눌러 결제될까 걱정되는 김복순은
  - I want 주문 내역 페이지에서 주문 최소 버튼을 크고 명확하게 찾고 싶다.
  - so that잘못 눌렀더라고 배송 전에 쉽게 바로잡을 수 있다.
- **상품 결제(신뢰성 결제 대행)**
  - As a 디지털 사용에 익숙하지 않지만, 스스로 필요한 물건을 사고 싶은 시니어 사용자 김복순은
  - I want to 관절에 좋은 영양제를 쉽게 찾고, 이해하기 쉬운 설명을 보고, 안전하게 결제하고 싶다.
  - So that 매번 자녀에게 부탁하지 않고 본인 손으로 직접 필요한 것을 할 수 있다는 자립감과 안정감을 느끼고 싶기 때문이다.
  - **배송 조회/알림**
  - As a 배송 상황이 궁금한 김복순은
  - I want 배송 단계가 봐뀔 때마다 카톡/문자로 알림을 받고 현재 위치를 확인하고 싶다.
  - so that 언제 상품이 도착하는지 안심하고 기다릴 수 있다.
  - **정기구매**
  - As a 매번 같은 상품을 찿기 번거로운 김복순은
  - I want 지난 주문에서 정기구매 설정을 하고싶다.
  - so what 구매했던 재품을 정기 구매로 간편하게 구매할 수 있다.

## 페르소나3: 이정호

- **UI 단순화**
  - As a 번잡한 광고와 UI로 인해 서비스 이용이 힘든 이정호는
  - I want 불필요한 정보나 광고 없이 플랫폼을 사용하고 싶다.
  - so that 복잡한 화면을 해석하는데 드는 인지적 부담을 줄일 수 있다.
- **접근성 프로필**
  - As a 디지털 환경 설정 변경에 어려움을 느끼는 백내장 환자 이정호는
  - I want 화면의 표준 모드와 고대비 모드 전환이 간편했으면 좋겠다.
  - so that 복잡한 설정 메뉴를 찾지 않고도 시야에 맞는 화면으로 전환해 더 편하게 서비스를 이용할 수 있다.
- **AI 요약**
  - As a 전문 용어를 이해하기 어려운 고령자 이정호는
  - I want 상품에 관한 정보를 간단하게 요약해주는 기능이 있으면 좋겠다.
  - so that 핵심 정보를 빠르게 이해하고 제품을 쉽게 선택할 수 있다.
- **TTS 지원**
  - As a 백내장과 노안으로 작은 글씨의 식별에 어려움을 느끼는 이정호는
  - I want 상품의 요약 정보나 설명을 음성으로 들을 수 있으면 좋겠다.
  - so that 글씨를 읽지 않아도 필요한 정보를 편안하게 얻고 시각적 피로를 줄일 수 있다.
- **가상 결제**
  - As a 복잡한 결제 과정에 실수가 두려운 고령자 이정호는
  - I want 실제 결제 전 미리 결제 과정을 연습해 볼 수 있는 가상 결제 기능이 있으면 좋겠다.
  - so that 결제 실수를 방지하고 자신있게 구매할 수 있다.
- **신뢰 시스템**
  - As a 온라인 판매자의 신뢰도를 구분하기 어려운 이정호는
  - I want 인증된 판매자나 높은 신뢰도를 가진 판매자를 쉽게 구분할 수 있는 마크가 있으면 좋겠다.
  - so that 믿을 수 있는 판매자를 쉽게 식별하여 안심하고 제품을 구매할 수 있다.
- **상품 검색**
  - As a 신중하게 구매하는 이정호는,
  - I want 상품 목록에서 인증 판매자 필터 기능을 사용하고 싶다.
  - So that 신뢰할 수 없는 상품을 걸러내고 검증된 상품만 비교할 수 있다.
- **구매 확정**
  - As a 거래의 신뢰성을 중요하게 생각하는 이정호는
  - I want 상품 수령 후 직접 ‘구매확정’을 눌러야 거래가 완료되었으면 좋겠다.
  - so that 문제가 있는 상품을 받았을 때 빠르게 대응할 수 있다.
- **회원가입**
  - As a 필수 기능에 대한 디지털 친숙도가 높은 이정호는
  - I want 카카오톡, 이메일과 같은 기존 계정으로 간편하게 회원가입을 하고 싶다.
  - so that 정보를 일일이 입력할 필요 없이 익숙한 계정으로 간편하게 서비스를 이용할 수 있다.

## 페르소나4:박철수

- **판매자 가입**
  - As a 컴퓨터 용어가 낯선 판매자 박철수는
  - I want 판매자 가입 시 사업자 등록증 사진 파일 하나만 업로드 하고, 가게 프로필만 입력하여 신청하고 싶다.
  - So that 어렵거나 이해하기 힘든 용어 입력 없이도 입점 절차를 마칠 수 있다.
- **상품 등록**
  - As a 상품 등록 절차가 복잡해서 포기했던 박철수는
  - I want 상품의 간단한 정보만을 입력하여 등록 승인을 요청하고 싶다.
  - So that 수십개의 옵션을 설정하느라 시간을 낭비하지 않고 빠르게 상품을 등록할 수 있다.
- **판매 현황판**
  - As a 복잡한 기능이 부담스러운 박철수는
  - I want 판매자 페이지에 접속했을 때, 내가 해야할 일과 판매 현황만 명확히 보고 싶다.
  - So that 광고나 마케팅에 방해받지 않고, 주문 처리와 배송 준비에만 집중할 수 있다.
- **AI 기능(향후 고도화)**
  - As a 접근성 개념에 익숙하지 않은 박철수는
  - I want 사진을 올리면 AI가 자동으로 대체 텍스트를 생성해줬으면 한다.
  - So that 별도의 학습 없이도 시각장애 고객도 내 상품을 이해할 수 있다.
- **구매 확정 후 판매자 정산 시스템**
  - As a 온라인 판매 정산 절차가 낯선 판매자 박철수는
  - I want 구매 확정 시점과 정산 금액을 명확히 확인하고 싶다.
  - So that 간단한 판매자 정산 시스템으로 헷갈리지 않고 편리하게 정산할 수 있다.
- **판매자 등급제 시스템**
  - As a 신뢰를 잃고 싶지 않은 판매자 박철수는
  - I want ‘접근성 인증 판매자’ 마크를 받아 고객에게 신뢰를 주고 싶다.
  - So that 시니어 이용자들이 내 상품을 믿고 구매하게 만들 수 있다.
